# 🤖 AI Estate Image Generator — Frontend

A modern AI-powered real estate frontend application that allows users to generate **property images, descriptions, valuations, and marketing content** using artificial intelligence.

This project is built for developers, startups, and real estate businesses that want to automate listing creation and marketing using AI.

# ⚙️ Environment Variables

Create a `.env` file in root directory:

```
VITE_API_KEY=your_api_key
VITE_AUTH_DOMAIN=your_auth_domain
VITE_PROJECT_ID=your_project_id
VITE_STORAGE_BUCKET=your_storage_bucket
VITE_MESSAGING_SENDER_ID=your_sender_id
VITE_APP_ID=your_app_id
VITE_MEASUREMENT_ID=your_measurement_id

VITE_REACT_API_URL=your_backend_api_url
VITE_REACT_APP_PUBLIC_MAILCHIMP_URL=your_mailchimp_url
```

# 🧠 How It Works

1. User enters property information
2. Frontend sends request to backend API
3. Backend generates AI content
4. Frontend receives generated data
5. UI displays generated:

- Property Image
- Property Description
- Property Valuation
- Marketing Poster

# 🚀 How To Run Locally

## Step 1 — Clone Repository

```
git clone https://github.com/mgrahul63/AI-real-estate-image-generator-frontend
cd AI-real-estate-image-generator-frontend
```

---

## Step 2 — Install Dependencies

```
npm install
```

---

## Step 3 — Run Development Server

```
npm run dev
```

Frontend runs at:

[http://localhost:5173](http://localhost:5173)
